# Flyer artwork (Aboriginal art)

Drop the **licensed** artwork file from the capability statement here (`.jpg`, `.png`, `.webp` or `.avif`).
`src/components/ArtworkBand.astro` picks up the first image in this folder and shows it as the band
above the footer on every page. Until a file is present, a plain sunset-gradient strip is shown.

Rules:

- Only use the artwork file supplied by NWCR, with confirmed web-use permission from the artist.
- Never generate, trace or imitate Aboriginal dot art with code, SVG or AI.
- Add the artist credit wherever NWCR and the artist agree it should appear.
